# 📸 Put the agent photo in this folder

Save your mother's passport-size photo **in this folder** with this exact name:

```
agent.jpg
```

Also accepted (any one of these): `agent.jpg`, `agent.jpeg`, `agent.png`, `agent.webp`

Once the file is here, just refresh the website — the photo appears **automatically** in two places:

1. The large portrait on the **hero agent ID card**
2. The portrait frame in the **About** section

Until a photo is added, the site shows a tidy **“SD” monogram** instead, so nothing ever looks broken.

### Tips for a good result

- Use a clear, well-lit, passport-style face photo.
- Portrait orientation (taller than wide) looks best.
- Resize to roughly **600–1000 px** on the longest side.
- Keep the file under about **300 KB** so the page stays fast.
- The photo is cropped automatically to fit; the face is kept near the top of the frame.

### Want a different file name?

Edit the `candidates` list near the bottom of `js/main.js`.
